# Jaza open-source SDK packages

This Turborepo hosts publishable Jaza client libraries (starting with `@jaza/node`).
`jaza-api` remains private; these packages call its public HTTP surface.

## Packages

| Package | Path | Description |
|---------|------|-------------|
| `@jaza/node` | [`@jaza-node`](./@jaza-node) | Node.js backend SDK |

## Scripts

```bash
npm install
npm run build
npm test
```
